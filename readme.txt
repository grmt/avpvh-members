Member login, access control, fee tracking and admin for AV Philips van Horne.

== Description ==

Manages the association's members: login, which pages and files each member
may see, membership fees, activities and the member administration. The
avpvh-bookkeeping plugin builds on it.

The plugin's interface is in Dutch.

== Installation ==

1. Copy the plugin to `wp-content/plugins/avpvh-members/`.
2. Activate it.
